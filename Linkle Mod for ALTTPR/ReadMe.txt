LINKLE MOD FOR A LINK TO THE PAST: REDUX
-----------------------------------------------

You need the original romhack, as this only edits Link's graphics.
Get it at: https://www.romhacking.net/hacks/2594/

The main file is "Z3RLinkleMod.ips" which MUST be applied over an already existing ALTTP: Redux Rom, use "HAIR_PATCH.ips" to restore the hair color to the Redux Blonde

To use pink hair, you should be able to just apply the pink hair patch from normal redux.

This is purely cosmetic and does not replace text, but there aren't many instances in the game where you're refered to as explicitly male so it shouldn't be that much of a problem.
